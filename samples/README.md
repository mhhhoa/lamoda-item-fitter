# Эталонные пары

Сюда кладутся пары «до/после» от подрядчика — они нужны для двух вещей:

- `fitter compare ./samples` — численно сравнить свою обработку с эталоном;
- `fitter calibrate ./samples --save presets/мой.yaml` — подобрать параметры так,
  чтобы результат сошёлся с эталоном.

Именование файлов:

```
samples/
    12345_before.jpg    исходник с цветным фоном
    12345_after.jpg     что вернул подрядчик
    67890_before.jpg
    67890_after.jpg
```

Распознаются также суффиксы `_до` / `_после`, `-before` / `-after`, `_src` / `_dst`,
`_in` / `_out`. Расширения — jpg, jpeg, png, webp.
