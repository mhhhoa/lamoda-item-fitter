# Замена фона на белый для карточек маркетплейсов

Пакетная обработка съёмки обуви: цветной студийный фон уходит в чистый белый под
требования Lamoda и Wildberries.

**Главное отличие от «удалить фон»:** отражение и контактная тень под товаром
сохраняются, цветной рефлекс с кожи и ткани снимается, а сам товар не меняется
ни на пиксель. Товар не перерисовывается нейросетью — для карточки маркетплейса
это обязательное условие.

---

## Установка

Делается один раз, занимает 5–10 минут.

**Windows**
1. Установите Python с [python.org](https://www.python.org/downloads/).
   При установке обязательно поставьте галочку **«Add Python to PATH»**.
2. Двойной клик по `install.bat`.

**macOS**
1. Установите Python 3 с [python.org](https://www.python.org/downloads/).
2. Двойной клик по `install.command`.
   Если macOS ругается на неизвестного разработчика — правый клик → «Открыть».

При первом запуске обработки докачается модель нейросети (~180 МБ). Нужен интернет
только в этот первый раз, дальше всё работает офлайн.

## Запуск

Двойной клик по **`run.bat`** (Windows) или **`run.command`** (macOS).
Через несколько секунд откроется вкладка в браузере. Командная строка не нужна.

Чтобы дать доступ коллегам с других компьютеров — запускайте `run-network.bat`
(или `run-network.command`). Готовый адрес для коллег программа напечатает
в окне при старте.

**Если окно ругается на занятый порт** — значит программа уже запущена в другом
окне. Ничего страшного: порт подбирается автоматически, и вторая копия просто
встанет на соседний. Задать порт вручную можно так: `fitter ui --port 7870`.

## Как пользоваться

### Вкладка «Пакет»
Перетащите кадры **или** впишите путь к папке (например `C:\Съёмки\неделя_42`).
Нажмите «Обработать всё». На выходе — архив с готовыми JPEG и HTML-отчёт.

### Вкладка «Настройка на одном кадре»
Подберите вид на одном кадре: ползунки, шторка «до/после», сразу видны метрики.
Устраивает — сохраните как пресет и используйте его на вкладке «Пакет».

### Вкладка «Сверка с подрядчиком»
Положите в папку пары файлов `артикул_before.jpg` и `артикул_after.jpg` и нажмите
«Сверить». Инструмент прогонит «before» через себя и численно сравнит с тем, что
вернул подрядчик. Готовый аргумент для руководителя вместо слов «получилось не хуже».

## Что означают настройки

| Настройка | Что делает |
|---|---|
| **Матирование** | Как находится товар. `rembg` — нейросеть, нужна для белого товара и лайфстайла с реквизитом. `simple` — без нейросети, быстро и офлайн, но не возьмёт белый товар на светлом фоне. |
| **Снятие цветного рефлекса** | Насколько убирать подкраску фоном с кожи и ткани. По смыслу это доля света, пришедшего на товар отражением от циклорамы — в студийной схеме обычно 0,1–0,25. Ставить больше, чем было рефлекса, вредно: товар перекрасится. Точное значение подбирает `fitter calibrate` по вашим эталонам. |
| **Сила отражения** | 1 — отражение как в оригинале. 0 — убрать тень совсем, товар «повиснет в воздухе». |
| **Порог дотяжки белого** | Ниже — фон белее, но светлый товар рискует слиться с фоном. Смотрите в отчёте метрику «выбелено товара». |
| **Степень модели фона** | 2 — обычная циклорама. 3 — сложный градиент или сильная виньетка. |
| **Цвет фона** | По умолчанию `#FFFFFF`. Если ваша категория требует светло-серый — поставьте, например, `#EFEFEF`. |

## Отчёт: как его читать

Каждый кадр получает вердикт, карточки сортируются худшими вверх.

- **готово** — прошёл все автоматические проверки, смотреть не нужно;
- **проверить** — что-то на грани, стоит глянуть глазами;
- **ошибка** — кадр не соответствует требованиям, отгружать нельзя.

Метрики в карточке:

| Метрика | Что значит |
|---|---|
| Фон в углах | Значение канала в углах готового файла. Именно его смотрит валидатор маркетплейса. Меряется по **реально записанному JPEG**, а не по картинке в памяти. |
| Сдвиг цвета товара ΔE2000 | Насколько изменился цвет самого товара. Меньше 1 — глазом не видно. Больше 3 — стоит проверить. Самая важная метрика: цвет товара на карточке менять нельзя. |
| Доля товара, выбеленного до фона | Светлый товар слился с белым фоном. Если больше нуля — понизьте порог дотяжки белого. |
| Площадь отражения до / после | Если после сильно меньше — отражение потерялось. |
| Разброс фона вокруг модели | Насколько фон был гладким. Большое значение — кадр сюжетный, инструмент к нему не применим. |

## Командная строка

Интерфейс и командная строка делают ровно одно и то же — берите что удобнее.

```bash
fitter run ./входящие -o ./готово           # обработать папку
fitter run ./входящие -o ./готово -p wildberries
fitter compare ./samples                     # сверить с эталонами подрядчика
fitter calibrate ./samples --save мой.yaml   # подобрать параметры по эталонам
fitter presets                               # список пресетов
fitter ui --host 0.0.0.0                     # интерфейс с доступом по сети
```

## Пресеты и спецификация

Все числа спецификации лежат в YAML-файлах в папке `presets/` и правятся без кода.

| Пресет | Для чего |
|---|---|
| `lamoda` | Основной. Размер кадра не меняется. |
| `lamoda_1500x2000` | То же + приведение к 1500×2000 (3:4) с полями. Товар не обрезается. |
| `lamoda_fast` | Без нейросети: быстро и офлайн. Для тёмного и цветного товара на чистой циклораме. |
| `wildberries` | Чуть мягче дотяжка белого. |

> **Проверьте числа перед первым боевым прогоном.** Стартовые значения взяты из
> открытых источников, а не выписаны из регламента: точные требования для вашей
> категории смотрите в кабинете партнёра Lamoda (раздел «Требования к оформлению
> фотографий»). Меняются прямо в YAML.

## Ограничения — честно

1. **Фон должен быть гладким.** Инструмент рассчитан на студийную циклораму с
   плавным градиентом. Сюжетный кадр с фактурным интерьером он не вытянет — но и
   не испортит молча: такой кадр попадёт в отчёт с пометкой «фон неоднородный».
2. **Цветной рефлекс снимается не полностью.** Подсветка товара цветным фоном
   неравномерна — сильнее на гранях, обращённых к циклораме, — а снимается она
   глобальной коррекцией оттенка. Взять её попиксельно значило бы рискнуть цветом
   товара, а это ровно то, чего делать нельзя. Поэтому коррекция намеренно
   консервативна: **перекрутить её вреднее, чем недокрутить** — сняв оттенка
   больше, чем его было, вы перекрасите товар. Её силу подбирает `calibrate`.
3. **Белый товар на светлом фоне — зона риска.** Здесь обязателен бэкенд `rembg`:
   классический `simple` белую сандалию на бежевом фоне просто не найдёт. Отчёт
   такой случай ловит метрикой «выбелено товара».
4. **Первый запуск требует интернета** — докачивается модель нейросети.
5. **Скорость.** Около 4 с на кадр 1500×2000 без нейросети и 8–12 с с нейросетью
   на обычном процессоре. Для 350 кадров — примерно час фоном. С видеокартой
   NVIDIA заметно быстрее: `pip install -e ".[gpu]"`.

## Как это работает

Обычный путь — «вырезать товар и залить фон белым» — здесь не годится: он убивает
отражение, оставляет цветную кайму по контуру и целиком зависит от идеальности маски.

Вместо этого используется **нормализация фона делением** (flat-field коррекция).

Студийный фон — это гладкое поле освещённости `B(x, y)`, а отражение и тень на полу —
то же поле, умноженное на коэффициент меньше единицы. Поэтому если поделить кадр
на `B`, чистый фон переходит ровно в белый, а отражение остаётся пропорционально
более тёмным, то есть **серой тенью на белом**. Тень не нужно вырезать и дорисовывать —
она сохраняется сама.

Порядок шагов:

1. **Грубая маска товара** — нейросетью или по отклонению от цвета фона.
2. **Фит модели фона `B(x, y)`** — полином по пикселям вне товара. Фит робастный
   с *асимметричной* отбраковкой: тёмные выбросы (отражения, тени) отсекаются
   агрессивно, светлые — мягко. Обычный МНК занизил бы модель, чистый фон ушёл бы
   в пересвет, а отражение исчезло.
3. **Уточнение маски по готовой `B`** — из уравнения композитинга альфа считается
   аналитически и становится пиксельно точной на шнурках, каблуках и строчке,
   где размытая маска нейросети мажет.
4. **Деление фона** → белый с сохранённой тенью.
5. **Сборка товара поверх.** Кромка — физическая смесь товара и фона, из-за чего
   на бежевом фоне белая кожа по контуру кремовая. Смесь разбирается обратно:
   в формулу входит не сам цвет товара `F`, а произведение `a·F`, которое равно
   `I − (1−a)·B` — без деления на `a`, а значит без взрыва шума на полупрозрачной
   кромке.
6. **Дотяжка белого** по сглаженной яркости (шум JPEG иначе не даёт углам дойти
   до 255), с защитой светлого товара.
7. **Проверка** — метрики считаются по записанному файлу.

Вся математика выполняется в линейном RGB: деление в sRGB исказило бы тона
гамма-кривой, фон не сошёлся бы в чистый белый.
