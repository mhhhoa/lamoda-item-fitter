LAMODA ITEM FITTER — КАК ЗАПУСТИТЬ
==================================

Запустите двойным кликом файл

    LamodaItemFitter.exe

Цифры в его имени — номер версии. В проводнике у него цветной значок, а в
колонке «Тип» написано «Приложение». Устанавливать ничего не нужно.


ЧТОБЫ НЕ ИСКАТЬ ПРОГРАММУ КАЖДЫЙ РАЗ

Запустите один раз файл

    Создать ярлык на рабочем столе.bat

Он попросит программу положить ярлык на рабочий стол — дальше запускайте
с него. Если папку с программой потом перенести, ярлык перестанет
работать: запустите этот файл ещё раз.

То же самое умеет кнопка «Создать ярлык на рабочем столе» в настройках
программы.


ЧТО ЕЩЁ ЛЕЖИТ В ЭТОЙ ПАПКЕ

Инструкция в Word — как пользоваться программой, с картинками.

Папка _internal — служебная. В ней библиотеки, без которых программа не
запустится. Запускать там нечего; удалять, переименовывать и переносить
оттуда ничего не нужно.


ЕСЛИ НАДО ПЕРЕДАТЬ ПРОГРАММУ КОЛЛЕГЕ

Копируйте папку целиком, вместе с _internal. Один только exe, вынутый из
папки, не запустится.


ЕСЛИ WINDOWS ПИШЕТ «Система Windows защитила ваш компьютер»

Так Windows встречает любую программу без платной цифровой подписи.
Нажмите «Подробнее» → «Выполнить в любом случае».

Чтобы это окно не появлялось совсем, блокировку снимают до распаковки:
правый клик по скачанному архиву → «Свойства» → внизу галочка
«Разблокировать» → «ОК», и только после этого распаковывать.
