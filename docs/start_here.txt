LAMODA ITEM FITTER — КАК ЗАПУСТИТЬ
==================================

Запустите двойным кликом файл

    LamodaItemFitter.exe

Это и есть программа. В проводнике у неё цветной значок, а в колонке «Тип»
написано «Приложение». Устанавливать ничего не нужно.


ПАПКУ _internal ОТКРЫВАТЬ НЕ НАДО

В ней лежат служебные файлы, без которых программа не запустится.
Запускать там нечего; удалять, переименовывать и переносить оттуда
ничего не нужно.


ЧТОБЫ НЕ ИСКАТЬ ПРОГРАММУ КАЖДЫЙ РАЗ

Правый клик по LamodaItemFitter.exe → «Отправить» → «Рабочий стол
(создать ярлык)». На рабочем столе появится ярлык, запускать можно с него.
Ярлык переносится куда угодно, а сама папка должна остаться на месте.


ЕСЛИ НАДО ПЕРЕДАТЬ ПРОГРАММУ КОЛЛЕГЕ

Копируйте папку целиком, вместе с _internal. Один только exe, вынутый из
папки, не запустится.


ЕСЛИ WINDOWS ПИШЕТ «Система Windows защитила ваш компьютер»

Так Windows встречает любую программу без платной цифровой подписи.
Нажмите «Подробнее» → «Выполнить в любом случае».

Чтобы это окно не появлялось совсем, блокировку снимают до распаковки:
правый клик по скачанному архиву → «Свойства» → внизу галочка
«Разблокировать» → «ОК», и только после этого распаковывать.


ЧТО ПРОГРАММА ДЕЛАЕТ

Приводит предметные фото к требованиям Ламоды: холст 1524 × 2200, товар
стоит на нижней линии отступа и отцентрован по ширине. Перетащите в окно
файлы или папку и нажмите «Обработать» — готовые кадры появятся
в «Загрузках».
