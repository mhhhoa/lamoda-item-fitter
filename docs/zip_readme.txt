LAMODA ITEM FITTER

СНАЧАЛА РАСПАКУЙТЕ АРХИВ ЦЕЛИКОМ. Прямо из архива программа не запускается:
Windows достаёт из него только один файл, а программе нужны все её файлы
сразу. Правый клик по архиву → «Извлечь всё…».

Дальше:

    1. Откройте папку LamodaItemFitter
    2. Запустите двойным кликом файл LamodaItemFitter.exe

Устанавливать ничего не нужно. Всё остальное в папке — служебные файлы;
открывать их не надо, а папку переносите только целиком.

Если Windows пишет «Система Windows защитила ваш компьютер», нажмите
«Подробнее» → «Выполнить в любом случае»: так Windows встречает любую
программу без платной цифровой подписи.

Остальное — в файле «!! КАК ЗАПУСТИТЬ.txt» внутри папки.
